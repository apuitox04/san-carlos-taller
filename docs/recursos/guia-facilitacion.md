# Guía de facilitación

## Propósito

Revisar la información disponible para el área urbana de La Fortuna y acordar quién aporta, valida, actualiza y autoriza cada cobertura necesaria para el piloto municipal.

## Duración y grupo

- Duración: 240 minutos.
- Horario de mañana: 08:00–12:00.
- Horario de tarde: 13:00–17:00.
- Participación: 24 a 30 personas.
- Organización: cinco mesas, una computadora preparada por mesa.

## Invitación

Solicitar a cada entidad:

1. una persona técnica que conozca los datos;
2. una persona con capacidad para acordar responsabilidades;
3. la lista de coberturas que puede aportar;
4. las restricciones de uso o acceso;
5. el nombre de quien valida futuras actualizaciones.

Entidades propuestas: Municipalidad de San Carlos, Registro Nacional/IGN, MINAE, SINAC–ACAHN, MAG, INTA, INDER, CFIA, CNE/CME, MOPT/CONAVI, ICE, AyA/ASADAS, MICITT, SUTEL/FONATEL, ICT, sector turístico, ADIFORT, academia y comunidad.

## Preparación técnica

1. Instalar QGIS LTR y confirmar acceso a GDAL.
2. Extraer el paquete en una ruta corta, sin caracteres especiales.
3. Abrir el proyecto QGIS y revisar que ninguna capa figure como ausente.
4. Confirmar EPSG:8908.
5. Probar lectura de GeoPackage, ráster, CSV y muestra LiDAR.
6. Ejecutar una exportación PDF y otra CSV.
7. Abrir el proyecto ArcGIS Pro en la computadora de demostración.
8. Confirmar la sesión autorizada para el mapa privado de ArcGIS Online.
9. Retirar nombres de propietarios, identificadores personales, especies sensibles e infraestructura crítica.
10. Guardar una copia intacta para restablecer cada computadora.

## Funciones

| Función | Responsabilidad |
| --- | --- |
| Facilitación | Controlar tiempo, pregunta y producto. |
| Relatoría | Registrar fuente, decisión, responsable y plazo. |
| Apoyo técnico | Resolver apertura, rutas y exportaciones. |
| Representación institucional | Validar aporte, condición de acceso y responsable. |

## Reglas

- La fuente, fecha, licencia, sistema de referencia y custodio se registran antes de usar una cobertura.
- Una celda NoData no representa ausencia de cambio.
- Una corrección de altura requiere una referencia vertical documentada.
- LoD2.2 queda en revisión hasta que la persona técnica asignada registre el resultado.
- La copia docente excluye información personal o sensible.
- Un acuerdo contiene responsable, plazo, formato y evidencia de cierre.

## Cierre

Recoger en una sola carpeta:

1. proyecto QGIS;
2. mapa PDF;
3. CSV del indicador;
4. matriz institucional;
5. lista de acciones.

Confirmar la persona que consolida los archivos y la fecha de la siguiente revisión.

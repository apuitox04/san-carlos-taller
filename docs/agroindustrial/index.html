SIMULACIÓN DIDÁCTICA · SIN DATOS DE CULTIVO

Qué cambia al calcular un índice

Reflectancias ficticias entre 0 y 1. Este cálculo no diagnostica un cultivo ni asigna una dosis.

NDVI (NIR − Red) / (NIR + Red)

NDRE (NIR − Red Edge) / (NIR + Red Edge)

Denominador cero: NoData. Cambiar una paleta no cambia estos valores.
